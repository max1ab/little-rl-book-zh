本书沿着一条连续的叙事线索介绍强化学习：先建立智能体与环境交互的基本图景，再深入价值学习和策略优化，最后讨论大模型强化学习与 AlphaGo Zero。

## 第一部分：基础

1. [强化学习究竟是什么？](/book/chapter-1) - 交互循环、马尔可夫性质与信用分配。
2. [强化学习如何实现？](/book/chapter-2) - 策略、模型、价值，以及它们的常见组合。
3. [实践笔记](/book/practical-notes)

## 第二部分：深入探索

3. [价值函数](/book/chapter-3) - 从动态规划、蒙特卡洛到 SARSA 与 Q-learning。
4. [策略优化方法](/book/chapter-4) - 策略梯度、GAE、信赖域方法与 PPO。

## 第三部分：规模化强化学习

5. [RL × LLM](/book/chapter-5) - 从 PPO、GRPO 到大模型强化学习基础设施。
6. [AlphaGo Zero](/book/chapter-6) - 改进、评估、自我对弈与完整训练闭环。
