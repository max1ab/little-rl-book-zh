---
title: 中英文术语表
description: 翻译期间统一维护的强化学习核心术语。
---

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| agent | 智能体 | 执行动作并从环境反馈中学习的主体 |
| environment | 环境 | 智能体所交互的外部系统 |
| state | 状态 | 对环境当前情形的描述 |
| observation | 观测 | 智能体实际接收到的信息 |
| action | 动作 | 智能体在某个状态下作出的选择 |
| reward | 奖励 | 环境对动作结果给出的标量反馈 |
| return | 回报 | 从某一时刻开始累积的未来奖励 |
| policy | 策略 | 由状态到动作选择的规则或分布 |
| value function | 价值函数 | 衡量状态或动作长期价值的函数 |
| trajectory | 轨迹 | 交互产生的状态、动作与奖励序列 |
| episode | 回合 | 从初始状态到终止状态的一条轨迹 |
| credit assignment | 信用分配 | 判断哪些历史动作应为结果负责 |
| on-policy | 同策略 | 使用当前策略生成的数据进行学习 |
| off-policy | 异策略 | 可使用其他行为策略生成的数据进行学习 |
