Neural networks

So far in this chapter, we have assumed that states
and actions are discrete and few enough to enumerate, making it possible to store Q in a table and update each (s, a) independently. This is problematic
for two reasons:
• Many real-world problems have continuous
state spaces (physics-based control tasks involving positions or velocities) or huge discrete ones (LLMs where the possible states are
all possible token sequences). We could never
visit and learn every cell during training.
• In the tabular case, each cell is learned in isolation, and the potential “closeness” between
states is not exploited. However, we can expect
the value function to be smooth across states,

75

i.e. we could generalize what we learn from
one state to its neighbors.
The fix is function approximation: replace the
table with a parametric function Qθ (s, a) and learn
θ. We typically use a neural network for Qθ , and this
is why we start talking about Deep Reinforcement
Learning.

The TD loss, i.e. the regression loss of the Q-network,
is not a good signal to track either. The regression
target is a moving quantity which (we hope) changes
over training as the policy improves and visits new
states. The TD loss is therefore not the value of
any fixed objective, and tracking it across training
steps does not really make sense. It may increase
while training is healthy (a better policy is found
and explores new regions of the state space), and it
